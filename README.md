# Universal AI

Universal AI is an AI-powered assistant designed to help users with drafting, summarizing, simplifying text, organizing ideas, analyzing non-sensitive images, and working with approved reference documents.

## Key Features

* AI-powered chat assistance
* Text drafting and rewriting
* Summarization and simplification
* Knowledge Base / RAG support
* Reference document management
* Non-sensitive image analysis
* Charts, diagrams, and visual content support
* Follow-up prompts for refining responses

## How to Use

1. Open Universal AI.
2. Start a **New Chat**.
3. Turn on the **Knowledge Base** when reference documents are required.
4. Enter a clear and specific request.
5. Review and refine the AI response.
6. Verify important information before using or sharing it.

## Important

Do not enter passwords, API keys, confidential information, or sensitive personal data unless explicitly approved.

AI-generated content should always be reviewed and verified by a responsible person before final use.
